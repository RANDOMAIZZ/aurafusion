# AuraFusion — музыка + экран + ПК в одном окне

Объединение **MusicRGB** (пульс подсветки в такт басу через OpenRGB) и
**overlay_visualizer** (прозрачная волна поверх окон/игр).

## Что нового
- **Один аудио-движок** на `pyaudiowpatch` (WASAPI loopback): спектр для волны + уровень/бас для RGB. Нагрузка CPU меньше, чем два захвата.
- **ПК следует за экраном как визуализатор**: скрин 96×54 каждые 0.5с → самый сочный цвет → плавно на волну И на железо. Режим `mix`: цвет с экрана + яркость качает бас.
- **Красивый тёмный неоновый интерфейс** (PySide6, сайдбар): Визуал / Подсветка ПК / Экран→ПК / Звук / Система. Живое превью обоих цветов + метр уровня.
- **Анти-лаг сохранён**: heartbeat в простое, Direct один раз, пауза 20с при старте ПК, нарастающий реконнект OpenRGB.
- Один `fusion_config.json`, один трей, один автозапуск.

## Запуск
```bat
run.bat
```
или
```bat
pip install -r requirements.txt
python main.py
```
Игры — в **Borderless / без рамки** (в Exclusive Fullscreen оверлея не видно — ограничение Windows).

## Режимы ПК (`Подсветка ПК → Режим`)
- **Микс** (по умолчанию): цвет с экрана, яркость от музыки.
- **Только экран**: чистый Ambilight, яркость = макс.
- **Только музыка**: старый MusicRGB — статичный цвет + пульс.

## Миграция
При первом старте подхватываются твои устройства из `E:\MusicRGB\settings.json`? Нет — возьми готовый `fusion_config.json` (уже создан с твоими B760+GPU, `#A6A200`, loopback `ARDOR GAMING H6`). Старые `settings.json` и `visualizer_config.json` можно оставить как бэкап.

## Что выкинуто осознанно
- Wallpaper-алгоритмы (avg/quant/vivid/center/hue/saliency) — остался живой экран, он точнее. Верну по просьбе как fallback-режим.
- SYS-эффекты всего экрана (Magnification zoom/shake) — рискованная штука, дёргала весь DWM. Локальные shake/zoom/flash волны остались.
- tkinter — весь UI теперь на PySide6 (один event-loop).
- `soundcard` — заменён на `pyaudiowpatch` (точные имена loopback + автоподхват колонки/наушники).
